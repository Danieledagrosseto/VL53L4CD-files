# VL53L4CD Breakout Host-Software Template

![Language](https://img.shields.io/badge/language-C-blue)
![Platform](https://img.shields.io/badge/platform-I2C%20sensor%20module-green)

This repository download contains the board reference images and schematic, the
VL53L4CD host-software template sources, and the usage guide. No IDE workspace
or project-specific setup files are required.

Start with the **[VL53L4CD README](VL53L4CD_README.md)** for the file list,
Arduino UNO R3 wiring, address discovery, a complete first-measurement sketch,
and integration notes for other platforms.
